# 포트폴리오 PPT 시안 — Kaggle PS S6E5 (F1 Pit Stops)

> 마크다운 슬라이드 아웃라인(시안). 각 `##` = 1슬라이드. **굵게** = 슬라이드 핵심, _기울임_ = 발표 노트.
> 톤: "브루트포스 아닌 **체계적 진단·데이터 기반 의사결정·엔지니어링**". 정직한 회고 포함.

---

## 1. 표지 — 결과 한 장
- **Kaggle Playground S6E5 — F1 다음 랩 피트스톱 예측 (ROC-AUC)**
- 최종 **Private 0.95460 · ~148/3023팀 · 상위 4.9%** (목표 0.95452 초과)
- 키워드: GBDT+NN 앙상블 · OOF 스태킹 · **공개 SOTA 자력재현** · d_eff 엔지니어링
- _바이브 코딩(Claude Code)으로 단독·헤드리스 운영_

## 2. 문제 & 데이터
- 이진분류: 다음 랩 피트스톱 여부 / 지표 ROC-AUC(확률) / train 439K·test 188K·양성 19.9%
- **합성(딥러닝 생성) 데이터** + 원본 F1 데이터(101K) 증강
- **함정 3가지**: ① row-level split(StratifiedKFold) ② `Driver` 고카디(887)·adversarial 분포시프트 ③ 합성 아티팩트 → **시계열 파생 FE가 노이즈**
- _데이터 본질 파악이 이후 실패/성공을 갈랐다_

## 3. 접근 — 파이프라인 한눈에
- **다양성 백본**: LightGBM · XGBoost · CatBoost · RealMLP · TabICL
- **누수 방지 OOF**(동일 5-fold seed 42) → **logit-space 메타 스태킹**
- 인코딩 분기(Driver TE / XGB freq / CatBoost native)로 멤버 decorrelation
- _공개 블렌더가 아닌 LR/HC 메타가 핵심(상위 4팀 공통)_

## 4. 🔑 전환점 — "천장은 데이터가 아니라 튜닝이었다"
- 정체기: 여러 세션을 **FE·신모델 같은 한계 레버**에 소진 (+0.0002급 반복)
- **상위 솔루션 분석** → 공통 백본 = @yekenot RealMLP 공개 노트북
- **진단**: 우리 RealMLP는 라이브러리 default(pytabkit TD)로 방치 — 공개 레시피보다 **−0.002 아래**
- _가장 큰 레버가 줄곧 공개돼 있었다. 문제는 우선순위였다._

## 5. 최대 레버 — RealMLP yekenot 레시피 자력재현
- **paired-OOF 비교**(yekenot 실제 OOF 파일)로 "시드/노이즈 vs FE"를 추측 아닌 데이터로 종결
- 단계 분해: params(+0.00099) → n_refit/Driver-native(+0.00026) → **풀 FE 41피처(+0.00040)**
- 결과: exp_046 0.9524 → **fefull 0.9540**(= yekenot 0.954093 매칭, 외부의존 0)
- _라이브러리 default 방치 금지 — 공개 강모델은 레시피째 재현한다_

## 6. 메타러너 & d_eff 돌파
- **메타러너 HC → ridge-LR-logits**: HC가 버리는 약체-직교 멤버를 ridge가 추출
- **진단**: 보유 OOF 72개의 유효차원 **d_eff = 1.08**(전부 corr 0.99 붕괴)
- **돌파**: **split 다양성**(같은 모델 7/10-fold) = 피처붕괴와 독립인 fold-구조 직교축(잔차 0.53)
- _점수는 "더 많은 같은 OOF"가 아니라 새 직교축에서 나왔다_

## 7. 결과 — 성능 궤적
- 0.95405(시작) → 0.95446(fefull) → 0.95449(ridge) → 0.95458(split) → **0.95460**
- 한 구간(막판 세션) **+0.00055** = 목표 격차(+0.00047) 초과
- 도약 = ① 진단 ② 메타러너 ③ d_eff축 (단일모델 짜내기 아님)
- _상위팀 0.9549까지 잔여 +0.0003은 수확체감 구간(정직하게 명시)_

## 8. 실패한 실험 (정직한 회고)
- 시계열 FE 7전 · Heavy FE 215조합(GBDT 흡수) · TabM 동화(corr 0.98) · CatBoost 강화(corr↑) · orig 풀 중복
- **공통 교훈**: 포화 멤버 개별↑은 스택 전이 0 — **측정은 개별 AUC 아니라 stack-add·잔차 d_eff로**
- **메타 실책**: "강화는 전이 안 됨"을 과적용해 RealMLP 재현을 지연시킴 → 교훈 영속화
- _실패의 정량 기록이 다음 우선순위를 정의했다_

## 9. 엔지니어링 — Claude Code 바이브 코딩
- **헤드리스 Kaggle 파이프라인**: 레지스트리 SSOT 노트북 생성 → push → output 회수, **비동기 병렬**
- **서브에이전트**: EDA·feature-smith·kaggle-runner(격리 탐색), 판정은 메인 순차
- **지식 영속**: ADR · 세션 핸드오프 · 모델별 SSOT · 실험 회고 · 메모리
- **EV 규율**: 트랙-천장 게이트로 토끼굴 방지
- _단독 운영을 규율 인프라로 확장 — 재현·인수인계 가능_

## 10. 교훈 (다음 대회 템플릿)
1. **상위 솔루션·공개 강모델 레시피를 먼저 재현**(default 방치 금지)
2. **메타러너 = ridge-LR-logits**(약체-직교 추출) > 단순 블렌더
3. **d_eff 축(split 다양성)** — 싸고 확실한 직교 소스
4. **판정 = stack-add·잔차**(개별 아님) · 노이즈/메타-overfit 인지
5. **프로세스 규율**(커밋·실험ID·회고·인프라 가드)을 시작일에 셋업
