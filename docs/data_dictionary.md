# 데이터 명세서 (Data Dictionary) — S6E5

> F1 피트스톱 예측 데이터의 **컬럼별 의미·범위**와 **F1 도메인 기초**를 정리한다.
> 수치는 train(439,140행) 기준 (2026-06-02). 통계 요약은 `docs/eda.md`, 누수 분석은 거기 4·5절 참조.

---

## 0. 한눈에 — 무엇을 푸는 문제인가
F1 한 랩(lap)마다 그 드라이버의 상태가 한 행(row)이다. **"이 드라이버가 *다음 랩*에 피트스톱(타이어 교체) 할 것인가?"** 를 확률로 예측한다 (`PitNextLap`, ROC-AUC).

---

## 1. F1 도메인 기초 (도메인 지식 보강용)

- **피트스톱(Pit stop)**: 레이스 중 피트레인에 들어와 **타이어를 교체**(때로 수리)하는 것. 약 2~3초 정지하지만 피트레인 통과로 20초 안팎을 잃는다. 그래서 **언제 들어오느냐(타이밍)** 가 전략의 핵심.
- **스틴트(Stint)**: 한 세트의 타이어로 연속 주행하는 구간. 피트스톱으로 스틴트가 나뉜다. 레이스 시작~첫 피트 = Stint 1, 첫 피트~둘째 피트 = Stint 2 …
- **타이어 컴파운드(Compound)**: 타이어 종류.
  - 드라이(마른 노면): **SOFT**(가장 빠르지만 빨리 닳음) < **MEDIUM**(중간) < **HARD**(느리지만 오래감)
  - 레인(젖은 노면): **INTERMEDIATE**(약한 비/젖음), **WET**(폭우)
  - 규정상 드라이 레이스에선 **최소 2종 컴파운드**를 써야 함 → 최소 1회 피트 강제.
- **타이어 마모/열화(Degradation)**: 랩을 거듭할수록 타이어 성능이 떨어져 랩타임이 느려진다. 마모가 심해지면 피트 타이밍이 온다.
- **언더컷/오버컷**: 경쟁자보다 **먼저** 피트해 새 타이어로 앞서는 전략(undercut) / **늦게** 피트해 빈 트랙에서 시간을 버는 전략(overcut).
- **예측의 직관**: 피트는 보통 **타이어가 닳고(TyreLife↑, Degradation↑) 레이스 중반(RaceProgress 중간)** 에 몰린다 → 이 신호들이 강한 피처.

## 3. 컬럼 상세 & 해석 포인트

### 컨텍스트
- **`Driver` (887)**: 익명 코드. test의 801종이 전부 train에 존재(coverage 100%) → native categorical로 충분, OOF 타깃 인코딩은 비교 실험 대상. 드라이버별 피트 성향(양성률 std 0.099) 존재.
- **`Compound`**: 컴파운드별 피트율 편차가 큼(HARD 32.8% ↔ WET 2.5%). 단 이는 "HARD가 잘 닳아서"가 아니라 **전략·스틴트 배치**(예: HARD를 마지막/장스틴트로 운용)의 결과일 수 있음 → 단독 해석 주의.
- **`Race`/`Year`**: 서킷·시즌별 전략 차이. 서킷마다 총 랩수·마모 특성이 달라 피트 패턴이 다름.

### 레이스 상태 (강신호)
- **`TyreLife`**: 가장 강한 피처 중 하나. 1~5랩 피트율 5.1% → 31+랩 41.4%로 단조 증가. 타이어가 닳을수록 피트.
- **`Stint`/`LapNumber`/`RaceProgress`**: 레이스 진행·스틴트 단계가 피트 타이밍과 직결. RaceProgress 40~60% 구간 피트율 36.9%(피트 윈도우).
- **`Position`**: 순위에 따라 전략(언더컷 방어/시도)이 달라짐.

### 파생/주의 컬럼 ⚠️
- **`LapTime_Delta`**, **`Cumulative_Degradation`**: 정의가 명확치 않고(부호·기준 불명), 극단값이 큼. shift로 재현 불가(미래 누수 직접 증거는 없음). `LapTime_Delta`는 타깃과 선형 상관 ≈0 → **ablation으로 유지/제거 판단** 권장.
- **`LapTime (s)`**: 최대 2507초 같은 극단값은 세이프티카/적색기/피트 인·아웃랩. 트리 모델엔 무해, 스케일 기반 모델은 클리핑 고려.

### 타깃
- **`PitNextLap`**: 다음 랩 피트 여부. 양성률 19.9%(≈1:4 불균형). 지표가 순위 기반 ROC-AUC라 클래스 가중 기본 미사용(decisions #004).
- ⚠️ **`PitStop`(현재) vs `PitNextLap`(다음)** 혼동 금지. `PitStop`은 현재 상태 피처, `PitNextLap`은 예측 대상.

## 4. 미확정 / 대회 description 확인 권장
- `PitStop` 의 정확한 정의(인랩? 피트 발생 랩?)와 `PitNextLap`과의 시점 관계.
- `LapTime_Delta`/`Cumulative_Degradation` 의 산출 기준(무엇 대비 delta인지, 음수 의미).
- `RaceProgress` 분모(실제 완주 랩수 vs 예정 총 랩수) — group max랩 대비 corr 0.89로 완전 일치는 아님.
